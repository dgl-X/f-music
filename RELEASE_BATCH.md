# Изменения 0.1.39 / Android 1.0.62

## Сервер

- Координация пяти фоновых очередей: восстановление не забирает активные задания.
- Асинхронная проверка пароля и ограничение параллельных попыток входа.
- Очистка и ограничение размера ограничителей запросов в памяти.
- Таймауты, ограничение вывода и локальные протоколы медиапроцессов.
- Ошибка ресурса декодера сохраняет исходную загрузку для повторной обработки.
- Дополнительная фильтрация специальных адресов endpoint федерации.
- Контролируемая обработка некорректного HTTP URL.
- Персональная статистика прослушивания и агрегаты использования.
- Рабочие зависимости PostgreSQL отделены от необязательной миграции SQLite.
- Проверки DEB включают установку, обновление и восстановление данных.

## Android

- Нативные настройки и статистика через API.
- Отмена HTTP-запросов, привязка к экрану, серверу и сессии.
- Защита от поздних ответов после поиска, выхода и смены сервера.
- Общий контроллер страниц библиотеки, истории, плейлистов, альбомов и артистов.
- Безопасная обработка неопределённого результата записи настроек.
- Освобождение ресурсов экранов и разрыв соединений вне UI-потока.
- Разделение кэша обложек по серверам; музыкальный кэш и правила очереди сохранены.

API v1 сохранён. Перед обновлением сервера остановить все старые API/worker;
смешанный rolling upgrade обработчиков не поддерживается.
Подробности: [WORKER_COORDINATION.md](WORKER_COORDINATION.md).
