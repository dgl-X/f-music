# Контракт федерации Family Music

> **Статус: experimental.** Используйте только между вручную сопряжёнными
> доверенными нодами и сохраняйте отдельную резервную копию identity.

Этот каталог содержит машинно-читаемую часть протокола. Identity, pairing, подписанный экспорт delta, push-подсказки `catalog.notify.v1`, удалённый индекс, объединённый поиск и проксируемый AAC Range-поток реализованы. Оригиналы файлов федерации остаются закрыты.

## Состав

- `schemas/node-v1.schema.json` — описание узла и его возможностей;
- `schemas/invitation-v1.schema.json` — одноразовое приглашение pairing;
- `schemas/error-v1.schema.json` — совместимый формат ошибок;
- `schemas/delta-v1.schema.json` — страница изменений каталога;
- `vectors/http-signature-ed25519-v1.json` — тестовый вектор подписи запроса.

Закрытый ключ из `vectors` намеренно опубликован и предназначен исключительно для тестов. Настоящая нода всегда генерирует собственный ключ вне репозитория.

## Правило совместимости

Внутри major v1 схемы расширяются только необязательными полями, поэтому у корневых объектов установлен `additionalProperties: true`. Старый reader обязан игнорировать неизвестные поля. Обязательное изменение требует нового major протокола.

Проверка выполняется обычной командой:

```bash
npm test
```

Полное описание находится в [`../FEDERATION.md`](../FEDERATION.md), порядок внедрения — в [`../FEDERATION_IMPLEMENTATION.md`](../FEDERATION_IMPLEMENTATION.md).
