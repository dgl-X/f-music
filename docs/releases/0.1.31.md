# Family Music Server 0.1.31 / Android 1.0.54

Приватный тестовый выпуск для полевой проверки Family Music Connect.

- Приёмник сначала загружает аудио на паузе и подтверждает готовность и позицию.
  Запуск выдаётся после ACK остановки источника.
- ACK содержит фактическое состояние плеера; устаревшие снимки не получают
  новую эпоху владения и не возвращают старый трек.
- Между WEB и Android передаются очередь, точный shuffle-порядок и история.
- Android обрабатывает команды и heartbeat в PlaybackService, независимо от
  открытого экрана приложения.
- Исправлен откат позиции при включении общего shuffle на Android.

API v1 расширен необязательными полями. PostgreSQL автоматически добавляет
`connect_state.navigation_json`; оригиналы музыки и пользовательские коллекции
не изменяются. Старые клиенты сохраняют прежний контракт передачи.

Для ручной проверки: WEB → Android → WEB, play/pause, seek, следующий/предыдущий,
shuffle, закрытие Activity, медленная сеть и потерянное подтверждение. При
недоступном источнике приёмник остаётся на паузе вместо запуска второго плеера.
