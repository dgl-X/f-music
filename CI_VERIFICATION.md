# Проверки сервера и выпуска

CI проверяет unit-тесты, синтаксис, секреты, npm-зависимости, совместимость
федерации, обмен двух нод, медиатракт, Connect, статистику, PostgreSQL и worker.
DEB проходит установку, обновление, сохранность данных и восстановление бэкапа.

Пакет собирается один раз и после проверки загружается в **черновик Release**.
Только после успеха всех jobs итоговое задание скачивает тот же DEB, проверяет
SHA256 и версию, затем публикует. Actions artifacts для передачи не используются.
При ошибке черновик остаётся неопубликованным. Опубликованный пакет не
перезаписывается повторным выпуском того же тега.

## Команды

```sh
npm test
npm run check:syntax
npm run test:federation:baseline
node scripts/check-repository-secrets.mjs
node scripts/check-git-history-secrets.mjs
```

Интеграции требуют отдельных пустых PostgreSQL-БД и переменных из скриптов.
Для worker имя выделенной БД начинается с fm_worker_test_.
scripts/ci-deb-smoke.sh меняет систему: запускать только в одноразовом стенде.
Настоящие Android, Bluetooth, Doze и сети требуют отдельной проверки устройства.
